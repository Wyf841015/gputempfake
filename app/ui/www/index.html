它做了什么（以及没做什么）

  • 只补温度。通过 LD_PRELOAD 让 resmon_service 的传感器探测拿到一个替代文件，内容就是 CPU 温度。磁盘温度、CPU 温度、GPU 占用率都不受影响。
  • 显示的不是真实 GPU 温度。是 CPU 温度顶替。GPU 满载时 CPU 未必同步升温，只能当「有没有过热」的参考。
  • 失败不会拖垮资源监控。拦截库缺失或被删时，系统只会打一行 warning 并继续启动，等于回到「没有 GPU 温度」的原始状态。
  • 真实的 GPU 传感器优先。本机若本来就有 GPU 温度节点，界面会判定「不适用」并禁用接管 —— 那种情况下接管只会把真值盖掉。
  • 卸载自动清理。卸载应用会删除注入配置并重启 resmon_service，系统恢复原样。
